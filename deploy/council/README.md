# ติดตั้งระบบตรวจร้านยาบนเครื่องของสภาเภสัชกรรม

เว็บนี้ใช้เตรียมงานในสำนักงานเท่านั้น ได้แก่ ค้นร้าน วางแผน กรอกฟอร์ม
ข้อมูลเภสัชกร และเก็บไฟล์ใน "ไดรฟ์" จึงรันบนเครื่องในแลนของสภาได้ และไม่ต้อง
เปิดอะไรออกนอกสภา ข้อมูลทั้งหมดเก็บบน NAS ของสภา

```
เครื่องพนักงาน ──http──▶ เครื่องที่รันเว็บ (Docker) ──SMB──▶ NAS ของสภา
                              │
                              └──https ขาออก──▶ เว็บ อย. / สภาเภสัชกรรม
```

## สิ่งที่ต้องเตรียม

1. **เครื่องที่รันเว็บ** 1 เครื่อง (Linux แนะนำ หรือ Windows ที่มี Docker Desktop)
   - Docker และ Docker Compose
   - RAM 2 GB ขึ้นไป เพราะการสร้าง PDF ต้องรัน Chromium
   - ออกอินเทอร์เน็ตขาออกทาง HTTPS ได้ เพราะเว็บต้องดึงข้อมูลจาก
     `porta.fda.moph.go.th`, `pertento.fda.moph.go.th` และ `www.pharmacycouncil.org`
   - **ไม่ต้อง**เปิด port ขาเข้าจากอินเทอร์เน็ต
2. **NAS: สร้าง shared folder 2 อัน**
   - `fda-drive` สำหรับหน้า "ไดรฟ์" พนักงานเปิดโฟลเดอร์นี้จาก Windows
     ได้ด้วย แต่ไม่ควรตั้งชื่อไฟล์ด้วยอักขระ `< > : " | ? *`
   - `fda-app-data` สำหรับแผน บันทึกการตรวจ และรูปถ่ายของระบบ ให้ระบบเข้าได้คนเดียว
   - สร้างบัญชีบน NAS ที่อ่านและเขียนได้**เฉพาะ**สองโฟลเดอร์นี้ และเปิด SMB 3
3. **ไฟล์แม่แบบ Word** ชื่อ `inspection-form.docx` วางไว้ที่ `templates/` ในโฟลเดอร์โปรเจกต์
   ไฟล์นี้ไม่อยู่ใน git เพราะมีชื่อเจ้าหน้าที่ ถ้าไม่มี ปุ่มดาวน์โหลด Word จะใช้ไม่ได้
   แต่ PDF ยังใช้ได้

## ติดตั้ง

```bash
git clone https://github.com/Setto-TSET/fda-license-scraper.git
cd fda-license-scraper/deploy/council
cp .env.example .env
nano .env                       # ใส่ PLANS_PASSCODE, NAS_HOST, ชื่อ share, บัญชี NAS
docker compose up -d --build
```

ตรวจว่าใช้ได้:

```bash
curl http://localhost/health
# {"ok":true,"plansStore":"file","photoStore":"file","driveStore":"file"}
```

จากนั้นเปิด `http://<IP หรือชื่อเครื่อง>/` จากเครื่องพนักงาน แล้วลองอัปโหลดไฟล์ในหน้า
"ไดรฟ์" ไฟล์ที่อัปโหลดต้องไปโผล่ใน `\\<NAS>\fda-drive`

ถ้าต้องการให้เข้าด้วยชื่อ เช่น `http://inspect.<โดเมนสภา>` ให้เพิ่ม DNS record ภายใน
(internal DNS) ชี้มาที่เครื่องนี้

## ความปลอดภัย

สิ่งที่ระบบทำให้เองแล้ว:

- แผน บันทึกการตรวจ ไดรฟ์ หน้าภาพรวม และการล้างแคช ต้องใส่ `PLANS_PASSCODE`
  ทุกครั้ง ถ้าใส่รหัสผิดเกิน 10 ครั้งใน 15 นาที เครื่องนั้นจะถูกพักการใส่รหัส 15 นาที
- จำกัดความถี่การค้นหาและการสร้าง PDF/Word ต่อเครื่อง เพื่อไม่ให้ระบบล่มหรือถูกใช้ยิงเว็บ อย.
- ตัวสร้าง PDF โหลดได้เฉพาะไฟล์ของระบบเอง จึงใช้หลอกให้เครื่องนี้ไปเปิดที่อยู่อื่นใน
  แลนของสภา (เช่น หน้าจัดการ NAS) ไม่ได้
- เว็บอื่นที่พนักงานเปิดอยู่อ่านข้อมูลจากระบบนี้ผ่านเบราว์เซอร์ไม่ได้ (ไม่เปิด CORS)
- ไฟล์ในไดรฟ์ที่ไม่ใช่ PDF หรือรูปภาพ จะถูกดาวน์โหลดเสมอ ไม่ถูกเปิดในเบราว์เซอร์
- container รันด้วยผู้ใช้ธรรมดา ไม่ใช่ root และ image ไม่มีข้อมูลแผนหรือไฟล์ของสำนักงานติดไปด้วย

สิ่งที่ฝ่าย IT ควรทำ:

1. **ตั้ง `PLANS_PASSCODE` ให้ยาวและเดายาก** อย่างน้อย 12 ตัวอักษร และเปลี่ยนเมื่อมีคนลาออก
2. **ไม่เปิด port ของเครื่องนี้ออกอินเทอร์เน็ต** และถ้าทำได้ ให้ firewall รับเฉพาะ
   วงแลนของสำนักงาน
3. **ใช้ HTTPS ถ้าทำได้** ตอนนี้ระบบรับ HTTP ธรรมดา รหัสผ่านจึงวิ่งในแลนแบบไม่เข้ารหัส
   ถ้าสภามี reverse proxy หรือใบรับรองภายในอยู่แล้ว ให้วางไว้หน้าเว็บนี้ แล้วตั้ง
   `TRUST_PROXY=1` ใน `.env` เพื่อให้ระบบเห็น IP
   ของเครื่องพนักงานจริง **ถ้าไม่มี proxy ห้ามตั้งค่านี้** เพราะจะทำให้ปลอม IP
   หลบการจำกัดความถี่ได้
4. **เก็บไฟล์ `.env` ให้คนอื่นอ่านไม่ได้** (`chmod 600 .env`) เพราะมีรหัส NAS และรหัสสำนักงาน
5. ใช้บัญชี NAS ที่เข้าได้เฉพาะสองโฟลเดอร์ของระบบนี้ และเปิด snapshot ของ NAS ไว้

## ส่วนที่ยังไม่เปิดใช้

เวอร์ชันนี้เปิดเฉพาะ **ค้นหา · จัดแผน · แผนที่ · ฟอร์ม** ส่วนการอัปโหลดไฟล์
(**ไดรฟ์**, ขั้น **เอกสาร** และหน้า **ภาพรวม** ที่นับจากเอกสาร) ปิดไว้ก่อน
และจะเปิดในอัปเดตถัดไป เมนูของส่วนนี้จะไม่แสดง และ API ของส่วนนี้ตอบ 404

เมื่อถึงอัปเดตนั้น ให้ตั้ง `FEATURE_DOCS=1` ใน `.env` แล้ว `docker compose up -d`
ต้องต่อ NAS ไว้ให้พร้อมก่อน เพราะไฟล์ทั้งหมดจะไปเก็บบน NAS

## เข้าสู่ระบบผ่านสภา

ตอนนี้ระบบใช้รหัสสำนักงาน (`AUTH_MODE=passcode`) เมื่อสภาเภสัชกรรมพร้อมให้ล็อกอินผ่านระบบของสภา
ระบบรองรับแบบ **gateway** อยู่แล้ว:

```
เครื่องพนักงาน ──https──▶ gateway ของสภา (ล็อกอิน) ──http + ชื่อผู้ใช้──▶ เว็บนี้
```

1. ให้ gateway / reverse proxy ของสภาตรวจการล็อกอินก่อนส่งทุกคำขอมาที่เว็บนี้
2. gateway ต้องส่งชื่อผู้ใช้ที่ล็อกอินแล้วมาใน header (ค่าเริ่มต้น `X-Remote-User`)
   และ**ต้องลบ header ชื่อเดียวกันที่มาจากเบราว์เซอร์ทิ้งก่อน** ไม่เช่นนั้นผู้ใช้จะปลอมชื่อได้
3. ให้ gateway ใส่ header `X-Auth-Proxy-Secret` เป็นค่าสุ่มยาว ๆ ค่าเดียวกับ
   `AUTH_PROXY_SECRET` ใน `.env` คำขอที่ไม่ผ่าน gateway จะไม่มีค่านี้และถูกปฏิเสธ
4. ตั้งใน `.env`:
   ```
   AUTH_MODE=header
   AUTH_USER_HEADER=x-remote-user
   AUTH_PROXY_SECRET=<ค่าสุ่มเดียวกับที่ gateway ใส่>
   TRUST_PROXY=1
   ```
5. เปิด port ของเว็บนี้ให้เฉพาะเครื่อง gateway เข้าได้ (firewall) ห้ามให้เครื่องพนักงาน
   เข้าตรงโดยไม่ผ่าน gateway

เมื่อเปิดโหมดนี้ ทุก `/api` ต้องมาจาก gateway พร้อมชื่อผู้ใช้ และระบบจะไม่ถามรหัสสำนักงานอีก

ถ้าสภาใช้ OpenID Connect (เช่น Keycloak, Azure AD) หรือ Active Directory โดยไม่มี gateway
แจ้งผู้พัฒนาพร้อมข้อมูลด้านล่าง เพื่อเพิ่มการเชื่อมต่อแบบนั้น

**คำถามสำหรับฝ่าย IT สภา**

- ระบบล็อกอินของสภาเป็นแบบไหน: gateway/reverse proxy, OpenID Connect, SAML หรือ AD/LDAP
- ถ้าเป็น gateway: header ที่ส่งชื่อผู้ใช้ชื่ออะไร และใส่ header ลับเพิ่มได้หรือไม่
- ถ้าเป็น OpenID Connect: issuer URL, client id/secret และ redirect URL ที่จะใช้
- ต้องจำกัดสิทธิ์ตามกลุ่มหรือไม่ (เช่น เฉพาะฝ่ายตรวจสอบ) และกลุ่มนั้นส่งมาทางไหน

## อัปเดตเวอร์ชัน

```bash
cd fda-license-scraper && git pull
cd deploy/council && docker compose up -d --build
```

ข้อมูลไม่หาย เพราะอยู่บน NAS ไม่ได้อยู่ใน container

## สำรองข้อมูล

ข้อมูลทั้งหมดอยู่ในสองโฟลเดอร์บน NAS ใช้ snapshot หรือ backup ของ NAS ตามปกติได้เลย

## แก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย |
| --- | --- |
| `docker compose up` ขึ้น `mount error(13): Permission denied` | ชื่อผู้ใช้หรือรหัสผ่าน NAS ผิด หรือบัญชีไม่มีสิทธิ์เข้า share |
| `mount error(95)` หรือ `Operation not supported` | NAS ไม่รองรับ SMB 3 ให้ลอง `NAS_SMB_VERSION=2.1` |
| เว็บขึ้น แต่บันทึกแผนหรืออัปโหลดแล้ว error | บัญชี NAS อ่านได้แต่เขียนไม่ได้ |
| ค้นร้านไม่ได้ | เครื่องออกอินเทอร์เน็ตไปเว็บ อย. ไม่ได้ ให้ตรวจ firewall หรือ proxy ขาออก |
| PDF ภาษาไทยเป็นกล่อง ๆ | image ไม่ได้ build จาก Dockerfile ของโปรเจกต์ ซึ่งมีฟอนต์ไทยมาให้ |
| ไฟล์ Word พิมพ์แล้วหน้าเลื่อน ลงชื่อตกหน้า หรือ ์ หาย | Word จัดหน้าใหม่ตามฟอนต์และเครื่องพิมพ์ของแต่ละเครื่อง ให้พิมพ์จาก PDF เสมอ ใช้ Word เฉพาะแก้ไข และติดตั้งฟอนต์ TH SarabunPSK (`web/public/fonts/`) ในเครื่องที่เปิด Word |
